## What to build

选中一条制作撤回，按该条快照恢复数量，其他补货、更正和制作保留。

## 实现要点

- 从原制作快照读取需恢复的数量，加到撤回时当前余额；同事务写反向变动、撤回状态和请求成功结果。
- 撤回已撤回记录返回既有状态，不再次入库；恢复溢出或任一错误时整次失败。
- 保留当前估算/精确标记及原低库存基准，分别记录制作和撤回时的标记。
- 零用量撤回只改变制作有效状态，不伪造库存流水；之后统计从有效记录重新得出。

## Acceptance criteria

- [ ] 多次制作可撤回中间任一条，仅恢复该条快照。
- [ ] 制作后盘点到 300，再撤回 80 颗，当前余额为 380，不恢复历史旧余额。
- [ ] 重复撤回、响应丢失和中断不多恢复；零用量撤回不改变库存。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
