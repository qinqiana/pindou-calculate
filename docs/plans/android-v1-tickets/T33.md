## What to build

小程序能真实完成制作记账、再次制作及撤回，并展示一致的使用统计。

## 实现要点

- 复用已拼/再拼的业务规则，以微信已经验证的原子写入方案保存余额、快照、流水与请求结果。
- 库存不足整次不写；零用量只记完成；同一动作连点和重开重试不重复扣减或计次。
- 撤回加回当前余额且保留基准和精度；编辑新用量不改旧制作快照。
- 统计仅汇总有效制作记录，平台差异不能改变已用量来源或把更正当消耗。

## Acceptance criteria

- [ ] 95 颗闭环、零用量、重复请求和任意一次撤回与 Android 一致。
- [ ] 盘点后撤回及修改图纸后再拼保持旧记录可解释。
- [ ] 真机中断没有半账或额外计次，成就随撤回正确变化。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
