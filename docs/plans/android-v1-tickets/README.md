Android 的朋友圈/小红书模板是**本地图片输出**，不是外部平台登录、发帖或 SDK 接入。先交付安卓，再推进小程序和外接，是用户本轮明确确认的顺序。

## 一票的完成方式

- 每票包含用户可见结果、贯穿输入/规则/持久化或文件/界面的实现要点、错误保护、样例及依赖。已有层只复用，不能为了声称“跨层”添加多余代码。
- 同一写操作校验所属数据区和输入，成功结果与余额/流水同次落盘；已成功的相同重试返回原结果，新动作才有新标识。各功能票自己实现数据保护，最终集成票只验证跨路径连接。
- 数量有限、可精确表示且为整数；库存非负。零与未填写分开，未知色号不自动猜成合法号，操作顺序不靠时钟单独决定。
- 制作和撤回保存当次快照；盘点不是消耗。整体确认用量不扣库存，旧确认版本不会被未确认编辑替换。
- 多人工作认领到人、目标阶段固定，各用独立分支/工作目录；共同数据合同由主会话协调后再改，不用并行写同一真源换取表面速度。
- 当前技术方案以真实样例和平台结果为准。满足需求最重要，不为固守技术方案而阻塞交付，也不因换技术降低数据保护与验收。
- 手机选择器、签名、获准微信环境、最终视觉属于实际输入/验收条件，不伪装成已经完成。不得操作用户微信界面。
- 代码 QA 遵守当前模型与委派规则；无法确认合格的不同模型时如实标明自行复核。不能把本次文档检查或既有 v1.1 QA 冒充后续代码独立 QA。

## 需要产品输入，但不阻止无关工作

- **签名保管与真机**：T01 首次打包前明确保管人和测试设备；T22/T27 复用同一签名身份，不把密钥写进任何交付物。
- **分享视觉**：T23/T24 先交真实样张，由用户决定素材含义、朋友圈画幅及排版；这些是可先制作再验收的产品工作，不预填尚未确认的字段。
- **颜色来源 D13**：目前沿用已接受、明确标注的社区版参考色；官方资料未到位不改变色号或库存。用户如决定不展示参考色，仅调整展示，不重写账本。
- **后续外接**：实际账户、调用额度、数据删除、Spark 环境或持久部署在相应票中核验。免费调用可以是候选优势，不代表任意服务、任意 API 或部署均已可用。

## 第一阶段：Android 必做（T01–T27）

1. **[T01 在 Android 真机安装并保存第一笔库存](T01.md)** — 前置：无。交付：安装后无需账号，录入一种拼豆库存，关闭并重开后余额和变动仍在。

2. **[T02 浏览、搜索和初始化 MARD 221 色库存](T02.md)** — 前置：T01。交付：首次打开看到完整 221 色，按色号搜索或按色系浏览，未录入颜色显示零。

3. **[T03 首次批量录入：预填 1000、预览后整批保存](T03.md)** — 前置：T02。交付：连续录入多个颜色，明确选入本批的条目经统一预览后一次保存。

4. **[T04 盘点更正与估算／精确标记调整](T04.md)** — 前置：T03。交付：把账面余额更正为实际数量，也可只更改精度标记，并能解释变化。

5. **[T05 补货按新总数入库并更新预警基准](T05.md)** — 前置：T04。交付：补货时填写现在共有多少颗，实际增加量和新基准自动记账。

6. **[T06 设置并展示百分比低库存预警](T06.md)** — 前置：T05。交付：用户设置预警比例，库存列表按各色基准提示余额偏低。

7. **[T07 查看库存变动记录与逐色前后余额](T07.md)** — 前置：T03。交付：用户能从库存查看何时、因何、哪些颜色发生了什么变化。

8. **[T08 本机图纸选择、预览和缩略图保存](T08.md)** — 前置：T01。交付：离线选择 PNG/JPG，预览正确图片，填写基本信息并在重开后找到缩略图。

9. **[T09 手工录入逐色用量并一次整体确认](T09.md)** — 前置：T02、T08。交付：逐项填写或修改图纸用量，用一个主按钮确认整份用量，离线也可保存。

10. **[T10 标题总数与逐色合计的差异确认](T10.md)** — 前置：T09。交付：用户录入可读的标题总数后，能看见它与逐色合计的差异并知情继续。

11. **[T11 图纸列表、详情和元信息编辑](T11.md)** — 前置：T09。交付：从列表找到图纸，查看确认用量、缩略图和备注，修改名称后重开仍有效。

12. **[T12 图纸需求、缺口、预计余量与可制作筛选](T12.md)** — 前置：T03、T11。交付：查看图纸时知道每色需要多少、现有多少、缺多少，并可区分足量和不足图纸。

13. **[T13 导出当前图纸补货清单并复制文字](T13.md)** — 前置：T12。交付：把当前图纸的全部正缺口保存为可读清单或复制给采购使用。

14. **[T14 完成一次制作并整体扣减（含零用量）](T14.md)** — 前置：T12。交付：实际拼完后点击已拼，足量时整次扣减并留下制作快照，不足时完整保留原账本。

15. **[T15 再拼一次与制作历史查看](T15.md)** — 前置：T14。交付：同一图纸可以明确再制作一件，并分别查看每次完成的时间和当次用量。

16. **[T16 撤回任意一次制作并恢复该次用量](T16.md)** — 前置：T04、T15。交付：选中一条制作撤回，按该条快照恢复数量，其他补货、更正和制作保留。

17. **[T17 编辑图纸用量且保留旧制作快照](T17.md)** — 前置：T10、T15。交付：修改图纸后，新制作使用新确认用量，旧制作记录仍保留原用量。

18. **[T18 展示总已用、逐色已用和完成作品数](T18.md)** — 前置：T16。交付：库存总览和颜色详情显示由真实制作记录汇总的使用成就。

19. **[T19 导出同一时点的完整账本备份](T19.md)** — 前置：T06、T16、T17。交付：用户主动导出一份包含库存、图纸和全部历史的完整可恢复文件。

20. **[T20 校验备份并预览整体替换差异](T20.md)** — 前置：T19。交付：选择备份后看见新旧数据差异，坏文件被拒绝，取消时原账本完整。

21. **[T21 整体恢复备份并保护中断前后的完整数据](T21.md)** — 前置：T20。交付：明确替换后完整恢复账本，任何阶段失败都能重新打开一套有效数据。

22. **[T22 同签名升级与重装后的本机备份恢复](T22.md)** — 前置：T21。交付：更新应用保留本地数据；重装后能从用户保存的文件恢复同一账本。

23. **[T23 朋友圈模板的本地预览与图片保存](T23.md)** — 前置：T11。交付：从图纸详情生成固定朋友圈图片，预览后保存到本机。

24. **[T24 小红书 9:15 模板的本地预览与保存](T24.md)** — 前置：T23。交付：切换到小红书模板，生成 1080×1800 的作品/图纸分享图片。

25. **[T25 真机连续录入、大字显示和触屏适配](T25.md)** — 前置：T07、T13、T18、T21、T24。交付：手机和平板上能连续输入、核对和保存，字体放大后关键操作仍可见。

26. **[T26 大账本离线运行与应用中断恢复验证](T26.md)** — 前置：T07、T13、T18、T21、T24。交付：在接近真实使用规模的数据上，断网、后台返回和中断后仍能可靠记账。

27. **[T27 交付可自用的签名 Android 安装包](T27.md)** — 前置：T22、T25、T26。交付：用户拿到可安装、自用、离线记账并能完整备份恢复的 Android 版本。

## 第一阶段旁路探索（T28，不阻塞 Android）

28. **[T28 验证已知点阵下无需文字识别的本地计数](T28.md)** — 前置：无。交付：用真实图纸证明哪些计数步骤能由本地算法完成，哪些仍需色号映射、人工校准或识别后备。

## 安卓交付后：小程序（T29–T37）

29. **[T29 在微信测试环境完成一笔可重开的本地记账](T29.md)** — 前置：T27。交付：安卓交付后，小程序测试版本能够保存一种库存并在关闭重开后保持完整。

30. **[T30 小程序首次库存录入和盘点更正](T30.md)** — 前置：T29。交付：小程序中可浏览 221 色，批量首次录入及盘点更正，重开不丢数据。

31. **[T31 小程序补货、预警与库存变动查看](T31.md)** — 前置：T30。交付：在小程序补货后可查看正确余额、百分比预警和变动原因。

32. **[T32 小程序本机图纸、手工用量与缺口查询](T32.md)** — 前置：T30。交付：在微信测试环境选择图纸，手工确认用量并查看和导出缺口。

33. **[T33 小程序制作、再拼、撤回和使用成就](T33.md)** — 前置：T31、T32。交付：小程序能真实完成制作记账、再次制作及撤回，并展示一致的使用统计。

34. **[T34 将 Android 完整备份导入小程序](T34.md)** — 前置：T33。交付：把 Android 的同一份备份交给小程序，预览差异后完整恢复并继续记账。

35. **[T35 小程序导出、预览和恢复完整本地备份](T35.md)** — 前置：T34。交付：小程序接续 Android 数据并新增操作后，仍能独立导出和恢复自己的完整账本。

36. **[T36 小程序双模板图片生成与本机保存](T36.md)** — 前置：T33。交付：小程序复用已确认的两套模板，预览并保存可读的分享图片。

37. **[T37 交付小程序测试版并验收安卓数据接续](T37.md)** — 前置：T35、T36。交付：提供可在获准微信环境实际使用的测试版本，证明迁移后还能完成本地闭环。

## 安卓交付后：自动计数与外接（T38–T43）

38. **[T38 自动提取图例用量并通过 148 颗真实基准](T38.md)** — 前置：T27。交付：主动选择一张图纸后获得真实自动生成的逐色候选，可核对并整体确认。

39. **[T39 部分识别、拒绝项和重复候选的整体确认](T39.md)** — 前置：T38。交付：识别不完整时能看见缺失风险、修改合法项，并按既有规则知情确认用量。

40. **[T40 重识别结果选择与迟到响应保护](T40.md)** — 前置：T39。交付：用户重新识别或边等边编辑时，能明确选择新候选，旧响应不会抢走自己的修改。

41. **[T41 无图例图纸的正式本体计数与逐色结果](T41.md)** — 前置：T38。交付：没有数量图例时，对经过样例验证的图纸输出可核对的逐色用量。

42. **[T42 本体计数疑点定位与必要的人工纠错](T42.md)** — 前置：T40、T41。交付：计数有疑点时能回到原图核对，修正后整体确认，并看见哪些步骤由人工完成。

43. **[T43 在 Android 与小程序验收自动计数及外接边界](T43.md)** — 前置：T37、T42。交付：两端都能取得、核对、确认自动计数结果，并证明外接异常不会伤害本地账本。

## 暂不发布为可领取开发票的后续候选

- **账号与本地账本归属**：先确认注册是否必需、登录/退出与当前本地数据的关系、换账号时怎样保护数据，再拆单一登录/绑定路径。
- **多设备同步**：先由产品负责人决定冲突时的数据真源与处理方式、离线操作合并/拒绝规则；不能先默认最后写入覆盖或自动合并制作记录。
- **广告**：待主体资格、平台位置和体验边界确定，再做一次真实展示/关闭及失败不阻断本地功能的闭环。
- **买断及购买恢复**：权益、跨平台互通和价格尚未确认；之后分别拆购买、防重复发权益、恢复购买、退款/失效等已确认路径，不先造订单系统。
- **更多品牌、厂商数量预设、普通照片转拼豆、图纸编辑器、公开发行**：不纳入本次实施草稿；不会通过技术准备票提前落地。
