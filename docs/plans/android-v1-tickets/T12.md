## What to build

查看图纸时知道每色需要多少、现有多少、缺多少，并可区分足量和不足图纸。

## 实现要点

- 按当前库存和当前确认用量计算每色缺口与预计余量；总需求由逐色求和，零需求不计颜色数。
- 不足色号显示明确颗数，负的预计余量只作为缺口展示，不写成负库存。
- 库存或确认版本变化后刷新比较和筛选，避免沿用打开页面时的旧结果。
- 预估和半成品状态不写库存；真正制作时仍须重新校验最新余额。

## Acceptance criteria

- [ ] A1=100、B1=10，需求 A1=80、B1=15、空白=5 时总需求 95，A1 余 20、B1 缺 5。
- [ ] 反复比较、切换图纸或筛选不改余额；库存变化后结果更新。
- [ ] 全零用量的总需求和涉及颜色数均为零，不发生除零或错误缺货。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
