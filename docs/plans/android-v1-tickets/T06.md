# T06 — 设置并展示百分比低库存预警

**负责人：** Android 库存负责人（认领时确定具体人员；主会话集成）

[根规格 Issue #1](https://github.com/qinqiana/pindou-calculate/issues/1) 已同步发布根规格 v1.2。实施以该版本的已确认阶段边界为准；历史 v1.0 中的首版 OCR/微信前置条件已由 v1.2 取代。

## What to build

用户设置预警比例，库存列表按各色基准提示余额偏低。

## 实现要点

- 允许用户输入自己的比例，不限于固定三个选项；检查输入为有效百分比，设置本地持久保存。
- 按当前余额/该色基准与比例比较，等于阈值也提示；首次未录入或零基准不做除法、不伪造百分比。
- 显示余额、基准及可解释的低库存状态；不与单张图纸缺口混用。
- 补货、更正、制作和撤回后查询刷新；只有首次录入及正向补货改变基准。

## Acceptance criteria

- [ ] 基准 1000、比例 10% 时，余额 100 提示，101 不提示。
- [ ] 补货后总量 1200 时阈值为 120；更正和后续扣减不重置基准。
- [ ] 未知/零基准没有除零或错误百分比，重开保留用户设置。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
