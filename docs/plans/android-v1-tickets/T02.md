## What to build

首次打开看到完整 221 色，按色号搜索或按色系浏览，未录入颜色显示零。

## 实现要点

- 精确采用 A26/B32/C29/D26/E24/F25/G21/H23/M15 的色号集合，色号是记账标识，显示颜色资料单独保存来源。
- 采用当前已接受的社区参考色并显示来源说明；D13 未决不构成另找官方色值的交付前置条件，后续展示替换不改变账本。
- 重复启动不重复建库存、不覆盖已有数量；没有录入的零库存不产生预警基准。
- 搜索支持常见大小写和首尾空白归一，数量与状态用文字展示；浅色块、长列表和空搜索结果可读。

## Acceptance criteria

- [ ] 九组数量及总数 221 正确，无重复、缺号或意外新增品牌维度。
- [ ] 搜索 C12 能定位该色；搜索无效色号显示无结果，不能创建新色号。
- [ ] 重新打开保留已录入 A1=100，其余未录入为零且没有基准。
- [ ] 用替代显示色资料验证更新只影响当前色块及来源说明，不改变色号、库存、已确认用量或历史记录保存的来源信息。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
