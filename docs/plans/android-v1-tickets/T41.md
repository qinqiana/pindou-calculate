## What to build

没有数量图例时，对经过样例验证的图纸输出可核对的逐色用量。

## 实现要点

- 使用已确认的点阵计数研究结果（若有）或其他可行方案；点阵恢复、网格线、OCR、聚类都不是固定技术前提。
- 准确限定制作区域并排除标题、行列编号、水印及其他非制作内容；不同格同色正常累计，同一格不能重复。
- 明确数量和色号映射分别来自哪里；需要人工提供点阵/代表色号时如实展示，不称为全自动识号。
- 白色制作格、空白格和未知格分开，近似色歧义不能静默映射成已有 MARD 号；最终用量经已有整体确认再保存。

## Acceptance criteria

- [ ] 多张预先人工逐格核对的受支持样例逐色、逐数正确，不能只对总数。
- [ ] 重复同色、边缘、白色和空白测试均正确；不支持样例明确提示而不是猜答案。
- [ ] 提交候选或确认不改变库存，旧制作快照不被替换。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
