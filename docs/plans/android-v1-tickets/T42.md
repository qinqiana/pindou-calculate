## What to build

计数有疑点时能回到原图核对，修正后整体确认，并看见哪些步骤由人工完成。

## 实现要点

- 为未知区域或不可靠结果提供可对应原图的位置/范围，避免只说识别失败而无法核对。
- 先复用放大查看和逐色修改；只有真实失败样本证明必要，才增加框选、拖角点、行列输入或网格校准。
- 纠错结果重新通过有效色号和数量校验，当前候选与旧确认版分离；迟到任务不得覆盖手工修正。
- 记录自动结果、人工映射/校准与最终确认的差别；失败和未完成不能当成零用量自动记完成。

## Acceptance criteria

- [ ] 压缩、倾斜、遮挡和近似色样本的疑点能找到原图依据。
- [ ] 人工修正后可整体确认，库存不变；不强迫所有导入都手动校准。
- [ ] 若新增校准手段，实际纠错结果改善且不会静默多计、漏计或改色号。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
