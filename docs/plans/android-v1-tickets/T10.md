## What to build

用户录入可读的标题总数后，能看见它与逐色合计的差异并知情继续。

## 实现要点

- 标题总数为可选核对信息；首版由用户填写，未提供时明确显示未提供，不从图片像素或名称猜测。
- 差异存在时显示标题数、逐色和、差值，并再次明确确认；不得强迫把用量改成标题数。
- 确认决定与当前用量版本关联；编辑到新的差异后不能沿用旧的知情确认。
- 保存差异与确认事实，供备份恢复和历史解释；异常字段本身仍需整数校验。

## Acceptance criteria

- [ ] 标题 148、有效用量合计 130 时显示差 18，知情确认后正式用量仍为 130。
- [ ] 修改逐色数量后重新判断差异；取消确认保留输入且库存不变。
- [ ] 标题未提供时不造数字，也不妨碍合法手工用量保存。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
