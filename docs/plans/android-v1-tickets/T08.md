## What to build

离线选择 PNG/JPG，预览正确图片，填写基本信息并在重开后找到缩略图。

## 实现要点

- 验证实际图片类型、解码结果、字节大小和像素尺寸，不能只按文件扩展名判断。
- 以 20 MiB、32 百万像素作为首轮容量验证起点，至少容纳 5000×3820、约 2.9 MiB 的原始样例。
- 保存名称、来源备注、可获得的图片尺寸及可辨认缩略图；制作网格行列与像素尺寸分开，未知信息留空。
- 处理系统选择器取消、读权限失效、坏图、存储不足及后台恢复；本机文件与图纸记录成功后才报告保存成功。

## Acceptance criteria

- [ ] 断网导入原始 PNG 和一张 JPG，重开后信息及缩略图可辨。
- [ ] 取消选择不造空图纸；伪装扩展名、坏图和超限输入被清楚拒绝。
- [ ] 导图全过程库存不变，不上传截图或相册内容。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
