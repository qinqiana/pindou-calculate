## What to build

用户能从库存查看何时、因何、哪些颜色发生了什么变化。

## 实现要点

- 从已保存操作及逐色变动读取，显示时间、原因、前后余额、差额和精度变化；不另造第二套流水真源。
- 操作内的多色变动成组展示，数量不变的精度调整有清楚文案。
- 保留本地操作顺序用于同时间或系统时钟改变时的排序；制作关联进入对应记录，相关能力接入后自然显示。
- 历史量增加时逐步加载，不能为了列表速度删除或截断历史。

## Acceptance criteria

- [ ] 批量录入可展开每色变化；仅改标记的记录可看懂。
- [ ] 时间回拨不把操作关系排乱；无历史有明确空状态。
- [ ] 记录页面仅查询，不改变库存或已用统计。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
