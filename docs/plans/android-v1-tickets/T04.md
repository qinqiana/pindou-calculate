## What to build

把账面余额更正为实际数量，也可只更改精度标记，并能解释变化。

## 实现要点

- 输入始终表示新的当前总数，允许增加或减少到零；差额由新旧余额计算，原因固定为盘点更正。
- 数量不变但精度改变也保存前后标记及变动记录；数量和标记都没变则不伪造一笔消耗。
- 更正不重置已建立的低库存基准，也不改变已使用量或完成次数。
- 沿用整批事务、请求防重和旧表单版本复核；保存失败保留表单。

## Acceptance criteria

- [ ] A1=100 更正为 70，余额 70，记录 -30，原预警基准不变。
- [ ] 70 颗由估算改为精确，数量不变且标记变化可追溯。
- [ ] 更正不被当作制作消耗；中断或错误不能只保存部分颜色。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
