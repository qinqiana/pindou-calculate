## What to build

小程序复用已确认的两套模板，预览并保存可读的分享图片。

## 实现要点

- 复用作品/图纸内容规则和排版决定，仅适配微信画布、图片加载和保存权限。
- 小红书输出仍是 1080×1800、9:15；朋友圈按已通过用户验收的模板，不重新擅定视觉字段。
- 不同确认版本、撤回状态、低清素材和默认隐私规则与 Android 一致。
- 处理权限拒绝、路径失效、保存取消和字体/布局差异，实际重新加载输出图核对。

## Acceptance criteria

- [ ] 微信真机生成的图片与预览一致，尺寸、裁切和文字可读。
- [ ] 默认无库存、历史、路径及错误完成状态。
- [ ] 取消或失败不改账本，不声称已在外部平台发帖。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
