## What to build

手机和平板上能连续输入、核对和保存，字体放大后关键操作仍可见。

## 实现要点

- 围绕库存录入、用量确认、缺口、制作/撤回、备份和分享走实际操作路径，复用已存在的页面行为。
- 处理数字键盘、焦点跳转、滚动位置和保存按钮可达性；避免输入一色就弹出新的页面。
- 色号、数字、估算/精确及错误状态均有文字，不只靠颜色；触控区、长名称和浅色块可辨。
- 平板调整布局不改变业务含义或创建独立一套表单逻辑；最小可用性由各功能票先满足，本票做跨页面真实场景复核和必要修正。

## Acceptance criteria

- [ ] 真实手机连续录入多色，数字键盘不会遮住确认动作，错误定位到对应条目。
- [ ] 系统字体放大后数字和按钮仍可读可点，平板无关键操作遮挡。
- [ ] 完整闭环的操作结果与标准字号一致。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
