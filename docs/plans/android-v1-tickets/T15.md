## What to build

同一图纸可以明确再制作一件，并分别查看每次完成的时间和当次用量。

## 实现要点

- 区分重复请求与新制作意图；只有明确再拼一次才创建新动作标识，重新检查余额并独立扣减。
- 历史按制作记录展示，不能用图纸的单一已拼布尔值代替；每次记录保留当时快照。
- 详情呈现完成/已撤回状态及可用动作，为撤回入口提供明确的单条记录目标。
- 库存不足时再拼失败，保留旧制作历史，不生成成功次数。

## Acceptance criteria

- [ ] 同图两次实际制作产生两条独立记录；重试其中一次不生成第三条。
- [ ] 各次的时间、逐色用量和前后余额可查看，列表不会隐藏再拼入口。
- [ ] 不足时旧记录和余额不变。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
