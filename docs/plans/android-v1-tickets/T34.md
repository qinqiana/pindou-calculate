## Parent

[根规格 Issue #1](https://github.com/qinqiana/pindou-calculate/issues/1) 已同步发布根规格 v1.2。实施以该版本的已确认阶段边界为准；历史 v1.0 中的首版 OCR/微信前置条件已由 v1.2 取代。

## What to build

把 Android 的同一份备份交给小程序，预览差异后完整恢复并继续记账。

## 实现要点

- 直接读取既有业务备份格式，检查全部关联、色号、版本、数量和缩略图，不依赖 Android 绝对路径或 SQLite 文件。
- 保留业务 ID、时间、资料来源、基准、确认和制作历史；在微信隔离准备全部数据后再整体切换。
- 先显示差异，用户取消不改现有数据；坏文件、超限和中断保留一套完整有效账本。
- 恢复成功失效原页面和未完成输入；重新查询后能继续制作、撤回和备份。

## Acceptance criteria

- [ ] 使用真实 Android 导出的同一文件，逐项对照余额、精度、基准、图纸、全部历史、缩略图和成就。
- [ ] 取消及准备/写入/切换中断均保护原数据，不产生自动合并。
- [ ] 在微信真机或获准测试者操作下完成，未验证部分明确标记。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
