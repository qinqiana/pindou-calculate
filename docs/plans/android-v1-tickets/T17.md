## Parent

[根规格 Issue #1](https://github.com/qinqiana/pindou-calculate/issues/1) 已同步发布根规格 v1.2。实施以该版本的已确认阶段边界为准；历史 v1.0 中的首版 OCR/微信前置条件已由 v1.2 取代。

## What to build

修改图纸后，新制作使用新确认用量，旧制作记录仍保留原用量。

## 实现要点

- 以新的确认版本保存编辑后的用量及差异确认，旧确认版本和旧制作快照不被覆盖。
- 编辑候选尚未确认时，制作入口清楚说明使用哪个已确认版本；提交时再次校验版本。
- 改名或改数量不把当前新版本标为已经制作；分享若展示状态，也依据当前版本有效制作判断。
- 沿用整体确认、有效色号和安全整数校验；保存失败或取消保留旧有效版本。

## Acceptance criteria

- [ ] 第一次用 A1=80 制作，改为 60 后再拼，旧记录仍为 80，新记录为 60。
- [ ] 有未确认编辑时不会悄悄按新数扣减；总数差异需重新知情确认。
- [ ] 编辑本身不改库存，撤回旧制作仍恢复旧快照。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
