## What to build

## 实现要点

- 整合库存、图纸、制作、备份和本地图片能力，保留已知平台限制与真实设备证据。
- 以 Android 原始备份作为迁移输入，完成一次新制作、撤回及再导出，核对相同数据语义。
- 视觉由主会话检查，用户或获准测试者执行微信实际交互；不能以网页预览代替真机。
- 依当前模型/权限规则完成合格复核并如实标明证据层次；公开发行、主体与商业化另行确认。

## Acceptance criteria

- [ ] 测试版中迁移、库存、制作和备份完整可用，用户数据没有被静默重建。

- [ ] 不需要外接识别、账号同步、广告或支付才算本阶段完成。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
