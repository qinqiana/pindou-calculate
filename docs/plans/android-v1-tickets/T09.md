## What to build

逐项填写或修改图纸用量，用一个主按钮确认整份用量，离线也可保存。

## 实现要点

- 按有效 MARD 色号录入非负安全整数；支持改号、改数、增删条目，重复色号作为歧义处理，不静默累加。
- 候选编辑与已确认版本分开；只有整体提交成功的确认版本进入预估和制作。
- 正式总数由有效逐色用量求和，零数量不计入涉及颜色数；全零用量可确认。
- 整体保存确认时间、录入方式和用量；失败保留输入，未经确认不落成可扣减版本。

## Acceptance criteria

- [ ] 多色中只改 C12 数量，一次确认保存全部合法项，其余项不丢失。
- [ ] 无 OCR、无网络仍能完成；坏色号或负数/小数/溢出不进入正式用量。
- [ ] 零用量可以确认；确认和重复保存不会扣库存。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
