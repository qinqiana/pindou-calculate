# T22 — 同签名升级与重装后的本机备份恢复

**目标阶段：** 安卓必做  
**负责人：** Android 交付负责人（认领时确定具体人员；主会话集成）  
**状态：** 拆分草稿，待用户批准；不是已发布 Issue 或应用完成记录。  
**验收映射：** 根规格 A29、A28；本票仅承担其中与交付行为对应的部分。

## Parent

[根规格 Issue #1](https://github.com/qinqiana/pindou-calculate/issues/1) 已同步发布根规格 v1.2。实施以该版本的已确认阶段边界为准；历史 v1.0 中的首版 OCR/微信前置条件已由 v1.2 取代。

## What to build

更新应用保留本地数据；重装后能从用户保存的文件恢复同一账本。

## 实现要点

- 沿用已确定的应用标识和签名保管方式，应用版本与规格/备份版本独立管理。
- 在实际 Android 文件选择器中验证导出位置能重新选择；不能只验证模拟器或开发目录。
- 升级如涉及本地存储迁移，失败应保留旧有效数据或明确拒绝，不能以清库解决兼容。
- 重装验证只在获准测试设备或测试数据区执行，先保留可读备份；不得卸载用户正在自用的版本来凑证据。

## Acceptance criteria

- [ ] 同包名/签名升级后库存、图纸、历史和设置不丢。
- [ ] 测试重装后重新选备份，恢复数量及缩略图正确。
- [ ] 交付物不包含私钥，且记录实际设备、系统、安装/升级方式和结果。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
