[根规格 Issue #1](https://github.com/qinqiana/pindou-calculate/issues/1) 已同步发布根规格 v1.2。实施以该版本的已确认阶段边界为准；历史 v1.0 中的首版 OCR/微信前置条件已由 v1.2 取代。

## What to build

在接近真实使用规模的数据上，断网、后台返回和中断后仍能可靠记账。

## 实现要点

- 以 221 色、100 张图纸、1 万条逐色变动及首轮 32 MiB 备份作为验证起点，记录设备、数据规模和峰值资源，不将建议值冒充已测结论。
- 测搜索/对比反馈、保存、分享和备份；低于体验目标的实际路径才做必要优化，不为未来容量重构。
- 复用各票已有故障场景，重点验证跨模块串联：旧表单遇新库存、提交后回显前中断、恢复后旧引用失效。
- 异常不能静默清库、删历史、截断图片关联或伪报成功；启动读取失败须保留原数据并说明恢复路径。

## Acceptance criteria

- [ ] 断网连续完成盘点、补货、手工图纸、已拼、撤回、备份和重开，数据一致。
- [ ] 记录实际耗时并对照规格观察线，未达项给出具体路径和修正结果。
- [ ] 中断与并发场景均只有完整前/后态，无重复扣减或跨数据区写入。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
