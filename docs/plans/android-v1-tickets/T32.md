## What to build

在微信测试环境选择图纸，手工确认用量并查看和导出缺口。

## 实现要点

- 适配微信图片/文件选择及缩略图持久保存，复用实际类型/尺寸/容量验证；取消和权限失败不造残缺图纸。
- 复用整体确认与标题差异知情确认，明确当前确认版本；候选输入不改库存。
- 按当前库存计算缺口和预计余量，并适配补货清单的本地输出/复制，不新增平台 SDK 依赖。
- 实际文件限制须能覆盖确认的核心样例或明确报告平台边界，不能静默裁掉图纸内容。

## Acceptance criteria

- [ ] 真机离线或可断网的已加载小程序环境完成图纸录入、确认和重开查询。
- [ ] 95 颗算例、标题差异和全零用量与 Android 结果一致。
- [ ] 取消、权限拒绝和导出失败不破坏输入或账本。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
