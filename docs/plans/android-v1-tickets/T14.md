**验收映射：** 根规格 A16、A17、A17b、A18、A19、A23、A24；本票仅承担其中与交付行为对应的部分。

[根规格 Issue #1](https://github.com/qinqiana/pindou-calculate/issues/1) 已同步发布根规格 v1.2。实施以该版本的已确认阶段边界为准；历史 v1.0 中的首版 OCR/微信前置条件已由 v1.2 取代。

## What to build

实际拼完后点击已拼，足量时整次扣减并留下制作快照，不足时完整保留原账本。

## 实现要点

- 点击已拼立即处理，不增加常规二次确认；在事务内重新读取最新库存和图纸确认版本，检查所有颜色。
- 同时保存逐色余额、变动、制作记录、当次名称/用量/来源快照及成功请求结果；任一步失败全部回滚。
- 同一动作连点、超时重试及提交后重开复用成功结果；新请求的旧版本冲突不能影响已成功请求的重试。
- 零用量也建立一次制作事实与请求成功结果，但不生成虚假逐色变动；估算标记及预警基准均按原规则保留。

## Acceptance criteria

- [ ] 95 颗样例不足时不扣；B1 补足后 A1=20、B1=0，保存一条制作。
- [ ] 连点、响应丢失和提交后进程中断均不重复扣减；事务中断不会出现一色已扣另一色未扣。
- [ ] 全零用量已拼一次，库存和基准不变；负库存、溢出或过期确认版本被阻止。
- [ ] 交接实际完成内容、验证方式、结果及未验证边界；技术方案可调整，但不能降低结果要求。
