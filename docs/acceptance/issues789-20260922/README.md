## 离线运行方式

`npm run build:app` 在构建时准备固定版本 Pyodide 314.0.7、NumPy 2.4.6、OpenCV 4.11.0.86 和 Pillow 12.2.0，约 27 MiB 压缩运行资源；生成目录不纳入版本控制。随应用打包源码、约 620.5 KiB 字形资源和静态 MARD 221 色卡。

视图层一次交付所选原图给 module Worker。Worker 的模块由随包字节建立，所有 Python 包读取均映射到内存中的随包资源；不允许网络回退。取消、编辑、换图、离开或超时会终止 Worker；30 秒后保留原图及编辑，给出重试或手工路径。输入只限用户选择的图片，不传库存或历史。

依据与许可证：[Pyodide Worker](https://pyodide.org/en/stable/usage/webworker.html)、[DCloud renderjs](https://zh.uniapp.dcloud.io/tutorial/renderjs.html)、[随包许可证](../../../app/static/recognition/licenses/README.md)。三包在手机可运行的结论来自实际执行，不仅是依赖清单。
