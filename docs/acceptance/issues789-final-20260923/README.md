## 本轮发现并修复

- 备份选择成功后读取失败：手机返回的 ContentResolver 是原生代理，没有可直接调用的 `openInputStream` JS 方法。文件适配器改用既有 Native.js 调用方式；正常和出错时均关闭流。原测试把返回对象当普通 JS 对象，未暴露问题；现已按真机观测调整测试，并覆盖读取中断和回调恢复。
- 识别超时、执行报错或返回格式无效时，空输入可能被保存成手工零用量。编辑页现在保留失败状态并拦住这次空确认，提供独立手工入口；用户明确选择手工后仍可保存零用量。不改库存规则、候选合同或备份格式。

两项均先取得失败证据再返修。`npm test` 最终 **95 项通过**；`npm run build:app` 成功。构建产物是 Android 应用资源，不是正式签名安装包。
