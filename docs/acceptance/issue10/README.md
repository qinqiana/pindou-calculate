## 本次改动

- 复现并修复单独末行横向移位时沿用上一行列起点的问题：开发图 S11 的 A19=15 移到独立末行后，原实现漏项，现按该行实际色块起点配对。
- 同一位置的重叠检测按字符位置去重；不同位置的同号项继续排除并分别保留原文、位置。一个数量被多个候选引用时不强行配对；未能配对的可见区域、前一道解析器留下的遗漏区域和不同文字读法均保留核对入口。
- 修复小字坐标换算可能得到零宽字符、导致后续取空裁块异常的问题。没有增加识字模型或改变既有识字阈值。
- 每条采用的图例候选可点击“图例原文”定位原图。改号、改数仍保留该行原证据；换原图后清除旧位置。原图、坐标及整份识别证据仅在会话中，确认版继续保存既有来源/风险摘要，不改变账本或备份格式。

## Android 实际路径

Xiaomi 14 Ultra，Android 15，官方 HBuilder 调试基座。最终算法资源随包，原图字节由 Android 文件 API 读取，进入真实离线 worker 和产品编辑页。此次使用随隔离测试包带入的原图，**未重新执行系统选择器点选**；系统选图未修改，既有证据在 #7–#9 收尾记录。

| 原图 | 排版/格式 | 自动结果 | 算法耗时 |
| --- | --- | --- | --- |
| S17 | 括号数量 / JPG | 7 色、931 颗，逐项全对 | 2.608 秒 |

强制结束基座并重新启动后，三类确认版、来源、风险和旧制作记录逐字段一致；在手机调用现有整体恢复入口恢复当前 v2 备份后再次一致。此次恢复验证使用实际导出的备份对象，不冒称新增的系统文件选择器测试。自动脚本的流程时长不冒充人工核对成本。精简证据见 [android.json](android.json)。
