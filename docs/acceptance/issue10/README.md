## 本次改动

- 修复单独末行横向移位时沿用上一行列起点的问题：开发图 S11 的 A19=15 移到独立末行后，原实现漏项，现按该行实际色块起点配对。
- 同一位置的重叠检测按字符位置去重；不同位置的同号项继续排除并分别保留原文、位置。一个数量被多个候选引用时不强行配对；未能配对的可见区域、前一道解析器留下的遗漏区域和不同文字读法均保留核对入口。
- 修复小字坐标换算可能得到零宽字符的问题。极小数量使用已有像素字体模型，不再让普通字体模型和重复阈值投票盖过窄笔画；局部增强同时检查字形分数与笔画覆盖率。低分色号在普通增强失败时分别读取明、暗笔画，并要求至少两次一致，避免水印背景碎片混进文字。
- 每条采用的图例候选可点击“图例原文”定位原图。改号、改数仍保留该行原证据；换原图后清除旧位置。原图、坐标及整份识别证据仅在会话中，确认版继续保存既有来源/风险摘要，不改变账本或备份格式。
- 为使大图在既有 30 秒限制内完成，将识字模型的 2×2 最大值运算改为等值的逐元素运算；模型权重、输入分辨率和超时限制均未改动。
