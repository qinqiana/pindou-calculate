# #13 长图分块与 #14 综合验收

2026-09-23；工作分支 `codex/issue-12-body-count`，承接 PR #16 和 #12。目标应用仍为开发版 0.2.0，算法 `pixel-glyph-0.12.0-dev`，备份 v2。

**#13 的分块和失败保护已实现并在 Android 验证；#14 已完成独立 Android 容器和自签 Release 构建，并在手机上完成启动、账本重启保存、媒体输出及 N25 识别确认。系统文件选择器的实际选取、覆盖更新、人工核对成本对照及用户验收仍未完成，不将 #14 标记全部通过。** 根规格已取消旧开发版备份迁移门槛，本轮未追加旧版兼容层。

## 改动

- 本体后备按整行划分区域，每块至多 8 行，通常不超过 256 格；每格只归属一块，取像素仍回到原图，边界采样有重叠。每块记录归属行、源区域及取样区域；结果按块身份替换聚合，不把重复消息累加。
- 每完成一块发送累计部分候选，正式用量仍需采用和整体确认。失败块、未处理行、未知格和未证明的外围覆盖分别保留位置及说明。30 秒停止、取消或编辑后保留已读部分和手工输入；旧请求继续受图片会话、编辑修订、确认版次和账本世代约束。
- 重新识别创建新任务并从头处理，不与上次已读数量相加；本轮没有增加单块续跑或图纸编辑入口。
- 相同像素的原有字形缓存继续复用。相同底色的 F21/F24 逐格读文字，不做色组多数传播或 RGB 猜号；没有增加人工校准、模型或依赖。原有 40000 格后备上限不变。
- 重复矩形同时验证横纵格距，支持已测非方格输入。手机只接收每色代表证据及全部疑点区域，避免把全量逐格调试数组传入页面。持久化复用现有来源、原始候选、人工修改和风险摘要；原图坐标仍只属于本次会话，不改变备份格式。
- 综合回归发现 L011、P002、P041 在任务起点已失去候选。根因是仅一个深色色块无法建立图例列间距；现在由同尺寸浅色闭合边框提供几何证据，三图恢复原数量。没有按答案补号、补数。

## 独立 Android 容器结果

独立包使用系统 WebView、SQLite、`ACTION_OPEN_DOCUMENT` 和 MediaStore；无网络权限、DCloud 手机运行库或离线 AppKey，Release APK 为 [pindou-0.2.0-release.apk](../../../artifacts/pindou-0.2.0-release.apk)。已安装 `com.pindou.ledger.debug` 的手机实测启动成功；首次空账初始化后写入 A1=100，杀进程重启读回，库存页展开显示 A1=100。原生文件接口将 20 字节测试文本写入下载目录，将 72 字节测试 PNG 写入 `Pictures/豆计`，文件存在及字节数已回读；这项检查不是完整备份恢复或分享模板验收。证据见 [独立容器记录](android-native.json)。Release 包名为 `com.pindou.ledger`，已完成构建和签名校验，尚未安装该 Release 包复验。

同一独立包用真实 N25 原图完成 Android 图片解码、离线 worker 识别、候选核对和确认，11 色 325 颗逐色全对，确认前后库存不变。N25 结果仍带“外围覆盖未证明”的部分风险，和算法边界一致。系统文件选择器已由应用打开，但手机禁止 adb 注入触控，未继续模拟选择 WebP；本项不以旧 DCloud 基座记录冒充新容器通过。

[离线证据](android-offline.json)：在应用渲染器与已附加 worker 上临时阻断 HTTP(S)，实际手工保存和 N25 自动 325 颗仍成功，记录 23 个本地资源请求、0 个远端请求。Wi-Fi 为 adb 保留，不声称开了飞行模式；识别 worker 的资源拦截另限制为已打包内容，没有截图上传入口。

[合计内存采样](android-memory-combined.json) 通过设备服务绑定关系定位主进程、直属 JS 子进程及本应用 WebView 渲染进程，目标约 2 秒采样。连续调试状态下，S14 本体处理前合计 PSS 525.8 MiB，**观测峰值 943.9 MiB**，约增加 418.1 MiB。包含基座和现有页面开销；它是采样峰值，不是精确瞬时峰值或纯算法内存。其他基座小程序、无关浏览器不计入。内存仍偏高，没有低内存手机验收，也未把分块宣传成已解决全部内存问题。
