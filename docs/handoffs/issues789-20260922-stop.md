## 导入会立刻识别，大图会把页面拖死

这点**没有改**。

点「确认导入这张图」之后会打开用量页，`onReady` 里只要内存里还有原图就调用 `startRecognition()`。选图时 `prepareOriginal` 还会先完整解码做预览。这一步不扣库存。

`01-148样例.png` 大约 5000×3820。第一次识别还要在页面里加载约 27MB 的 Pyodide / NumPy / OpenCV / Pillow。用户导入这张后界面卡死。当时 logcat 是连续 GC，以及 Weex `IPCFutexPageQueue` 一直在等。30 秒超时若界面线程已经堵住，用户看不到「取消识别，继续手工」。
