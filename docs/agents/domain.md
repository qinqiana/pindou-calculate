# Domain docs

本仓库采用 single-context：根目录 `CONTEXT.md` 维护领域词汇，`docs/adr/` 在出现必要架构决议时按需建立；没有多上下文目录。

## 读取规则

- 调查代码、讨论概念或设计验收前，读取根目录 [CONTEXT.md](../../CONTEXT.md)，使用其中的术语。
- 开发与验收的完整需求读取根目录 [SPEC.md](../../SPEC.md)。历史需求和确认记录只用于追溯，不另建竞争真源。
- 涉及架构取舍时，读取 `docs/adr/` 中相关记录。目录或文件尚不存在时继续任务，只有产生值得保留的决议才新建。
- 术语缺失或出现含义分歧时，按 domain-modeling 技能澄清并更新词汇表；词汇表不保存工程实现细节。
- 发现规格或已有决议之间的实质冲突时，明确指出来源与影响，按当前用户授权处理，不能静默改写已确认边界。
