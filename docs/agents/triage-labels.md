# Triage labels

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者判断 |
| needs-info | needs-info | 等待必要信息 |
| ready-for-agent | ready-for-agent | 规格足够明确，可交代理推进对应任务 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 不予实施 |

技能使用某个角色时，采用表中对应标签。`ready-for-agent` 表示任务准备状态，不代表运行验收已通过，也不替代费用、部署或公开发行所需授权。保留仓库已有的其他标签。
