### 真图数据集切分与冻结：可执行规则清单

1. **真图本体永不进 Git、不进 APK、不进任何公开渠道**；只留在本机训练/评测目录。仓库只放：清单（`samples.json` 类）、来源登记（`sources-*.md` 类）、参考答案、统计数字。
2. **来源清单是硬门槛**：每张真图必须有来源 URL 或“用户提供”登记；无稳定来源的素材不入集（沿用 sources-v03.md 对 Sinyuel 素材的排除先例）。来源分组（source_group）保守标注，不冒充版权认证。
3. **切分按来源组而不是按图随机**：同一作者/同一系列的图必须同组同侧（沿用现有 “grouping_rule”），避免同系列泄漏到训练侧造成虚高指标。
4. **社交平台截图（小红书等）默认只进测试/验证组，不进训练组**【推断性建议】：这些图权属最不清，用途越接近“研究评估”越稳；训练主体用合成数据。
5. **用户自制图与工具导出图（BitBead/Pixelbead 公开页）**：同样按来源登记；站点公开不等于授权训练，仍按第 4 条原则处理；工具导出图还需注意工具本身的条款【未核实：BitBead/Pixelbead 站点条款未取得】。
6. **冻结即定案**：分母、清单、参考答案在首次正式评测前冻结（沿用 `samples.json` 的 `frozen_before_first_ocr_run` 先例）；冻结后新增图只能进新的追加集，不回改历史分母。
7. **公开报告只写数字与统计**；确需展示图时，用最小裁块 + 标注来源 + 说明用途，并优先用用户自制或已确认可引用的图；整图一律不出现在仓库、报告、Issue、README。
8. **权重与训练产物不进 Git**（用户已定）；学生模型权重随 APK 分发时，训练数据来源说明写入第三方许可页。
9. 任何来源方要求删除的图，从本机训练集与评测集同时删除并登记。

| fonts-noto-mono（Noto Mono） | SIL OFL-1.1 | 允许 | 同 Liberation | 可用 |
| noto-cjk（Noto CJK） | SIL OFL-1.1 | 允许 | 同 Liberation | 可用 |
| fonts-ubuntu（Ubuntu Font Family） | Ubuntu Font Licence 1.0 | 条款上允许（见下），但**该许可不在 Apache/MIT/BSD 白名单内**，Debian 判定其不符合 DFSG | 同上 | **建议替换或用户特批** |
| fonts-urw-base35（URW base35） | **AGPL-3.0 with Font exception** | 例外条款只字面上覆盖嵌入 PostScript/PDF 文档，渲染 PNG 训练图不在其字面范围；AGPL 在本项目政策中整体排除 | 同左 | **按政策排除/替换** |
| xfonts-base（X11 点阵字体） | MIT 式 / 公有领域混合 | 允许 | 允许；保留声明 | 可用 |

关键逐字条款：

1. **SIL OFL-1.1**（Liberation / Noto Mono / Noto CJK 共用；官方文本 <http://scripts.sil.org/OFL>，全文已收录于 font-notices.txt）：
   > “The OFL allows the licensed fonts to be used, studied, modified and redistributed freely as long as they are not sold by themselves.”
   第 5 条：
   > “The Font Software, modified or unmodified, in part or in whole, must be distributed entirely under this license… **The requirement for fonts to remain under this license does not apply to any document created using the Font Software.**”
   【推断】用字体渲染出的整页图纸（PNG）属于 “document created using the Font Software”，不背负 OFL 的许可传递义务；OFL 管的是字体文件本身的分发（不单独卖字体、派生字体不得用 Reserved Font Name、字体副本须带许可），不管渲染产物。因此**渲染成图训练、glyphs.json 模板随应用分发均可行**，前提是继续保留许可声明（现行 font-notices.txt 做法满足）。

2. **Bitstream Vera / DejaVu**（font-notices.txt 收录全文）：
   > “Permission is hereby granted, free of charge, to any person obtaining a copy of the fonts accompanying this license (“Fonts”)… to reproduce and distribute the Font Software, including without limitation the rights to use, copy, merge, publish, distribute, and/or sell copies of the Font Software…”
   限制仅涉及：派生字体须改名（不含 “Bitstream”/“Vera”）、不得单独卖字体。对渲染用途无限制。官方上游：<https://dejavu-fonts.github.io/>

3. **Ubuntu Font Licence 1.0**（font-notices.txt 收录全文）：
   > “The requirement for fonts to remain under this licence does not require any document created using the fonts or their derivatives to be published under this licence, as long as the primary purpose of the document is not to be a vehicle for the distribution of the fonts.”
   条款本身允许渲染产物自由使用；但注意 Debian 官方判断（同一文件收录）：
   > “The Debian Project considers the Ubuntu Font License 1.0 to not be an acceptable license for inclusion in Debian under the Debian Free Software Guidelines.”
   【推断】因本项目许可政策只接受 Apache-2.0/MIT/BSD 类，UFL-1.0 不在白名单，**建议把合成渲染中的 Ubuntu 字体替换为 Noto/Liberation/DejaVu 等价字体，或由用户明确特批例外**。

4. **urw-base35 = AGPL-3.0 with Font exception【事实】**（font-notices.txt 收录；上游 <https://github.com/ArtifexSoftware/urw-base35-fonts>）：
   例外条款逐字：
   > “As a special exception, permission is granted to include these font programs in a Postscript or PDF file that consists of a document that contains text to be displayed or printed using this font, regardless of the conditions or license applying to the document itself.”
   【推断】该例外字面只覆盖“把字体程序嵌入 PS/PDF 文档”，不覆盖“把字形渲染成 PNG 训练图并拿去做训练/随应用分发产物”。叠加本项目“AGPL 排除”政策，**结论：从合成渲染链路中移除 urw-base35 字体**（DejaVu/Liberation/Noto 可覆盖同类衬线/无衬线字形）。如确有不可替代字形需求，需用户另行裁决。

5. **xfonts-base**：各子字体为 MIT 式授权或明示 “Public domain font. Share and enjoy.”（font-notices.txt 收录全文），可用。

6. **训练产物（glyphs.json 字形模板、学生模型权重）是否算字体“派生作品”**【推断】：glyphs.json 是字形栅格模板，接近“文档/图像产物”而非可安装字体文件，OFL/Vera 均不把义务传到这类产物；学生模型权重是从渲染图学到的统计参数，与字体文件的距离更远，上述许可均无条款声索此类产物。无一手文本直接讨论“字体→渲染图→模型权重”链条，此结论为推断，正式发行前建议用户自行确认。
