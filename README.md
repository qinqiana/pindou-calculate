# 豆计 🫘

一款面向个人拼豆爱好者的 Android 工具，帮你管理手头的豆子、核对图纸用量、算清还缺哪些颜色，并在拼完后记录消耗。

从「这张图的豆子够不够？」到「拼完还剩多少？」，让每一次制作都有账可查。

## 能做什么

- **管理豆仓**：按 MARD 221 色号记录库存，支持搜索、按色系浏览、批量盘点与补货，以及自设百分比的低库存提醒。库存可标记为估算或精确数量。
- **整理图纸用量**：导入 PNG、JPG 或 WebP 静态图纸，在手机本地识别用量，也可以手工录入、修改和整体确认。
- **算清缺豆**：对照图纸需求与现有库存，查看每种颜色需要多少、手头有多少、还缺多少。查看和确认用量不会扣库存。
- **记录制作**：拼完后点击「已拼」扣减库存；同一图纸可以「再拼一次」，误记的制作记录可以撤回。
- **看见积累**：查看累计已用颗数、各色已用颗数和完成作品数。
- **备份与分享**：手工导出完整账本备份、预览差异后恢复；生成适合朋友圈或小红书的分享图片并保存到本机。

无需注册，库存、记账和图纸识别均在本机完成，可离线使用。屏幕色块用于辅助辨认，不代表 MARD 官方精确色值。

## 怎么用

**录入库存 → 导入图纸并确认用量 → 查看缺豆 → 拼完记账**

1. 先把已有豆子的色号和数量录入豆仓；数量不确定时可以标为估算。
2. 导入想拼的图纸，逐色核对识别结果，补充或修改后确认用量。
3. 查看缺口，决定先拼哪张图、需要补哪些颜色。
4. 实际完成后记录「已拼」，库存和制作统计随之更新。

## 当前进度

当前为 **0.2.2 自用开发版**，优先支持 **Android 10 及以上**，尚未正式公开发行。微信小程序是后续方向。

本地识别已接入，但仍受图纸版式、清晰度、水印和色号范围影响。识别结果需要对照原图核对，不保证任意图纸都能自动准确计数；有疑点时可手工修正后再确认。

最新版 APK 已完成构建、签名和静态校验，尚未完成该包的真机安装验收。安装包、校验信息及升级注意事项见 [自用安装包说明](artifacts/README.md)。

**升级前请先备份。** 0.2.2 与 0.2.1 使用相同签名，可覆盖安装；不能覆盖安装 0.2.0。旧版迁移需先导出并核对备份，再卸载、安装和恢复，具体步骤见 [Android 安装与构建交接](docs/qin-apk-handoff.md)。

## 开发者入口

页面使用 Vue 3、TypeScript 和 uni-app H5 构建，随安装包放入 Android 系统 WebView；账本通过原生 SQLite 事务保存，文件选择与图片输出使用 Android 系统接口。本地识别算法和运行资源随包提供，手机无需下载模型或上传图纸。

使用 Node.js 24 和 npm，在仓库根目录运行：

```sh
npm ci
npm test
npm run build:web
```

安装依赖和首次构建准备识别资源时需要联网。网页资源输出到 `dist/build/android-assets`，供 Android 容器使用；网页构建或浏览器预览不能替代 Android 真机验收。

Android 打包所需的 JDK、SDK、Gradle 和签名配置见 [Android 安装与构建交接](docs/qin-apk-handoff.md)。
