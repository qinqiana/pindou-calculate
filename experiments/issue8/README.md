## 根因与当前路径

用户只提供原始图片；不要求裁框、行列数、代表色号或调阈值。识别器不读样例清单、参考答案或网站数据，不使用文件名/单图坐标规则。

1. 原图只解码一份，按128行生成有限预览，原分辨率局部读字，避免全幅RGB与边缘缓冲重复叠加。
2. 既有图例路径自动匹配同条括号、右侧数字、下方数字；断笔合并、粘连切字、多阈值及数量负号/小数保护仍保留。
3. 0.2仍假定底部图例，旧逐格路径又要求四边编号逐字读清，因此新网站的侧边图例和无图例网格全部失败。0.3新增**自动找网格 → 逐格读色号 → 按色号累加**，复用已有小字分类器，不用颜色最近邻代替色号。
4. 短格线的横纵间距须一致；线条检测落入半格/三分之一格时，用重复方格内部轮廓重新估计。几何位置只是候选，外围是否截断未证明时保持`partial`。
5. 图内连在一起的制作格曾被矩形检测当作图例，阻断后备；现在仅忽略落在网格内部的这些误检框，外围未知图例继续阻断。小字号`20`曾被切成`2()`或`00`，现在只在后备读字失败时比较相邻切点及数字/字母证据，既有图例切割不受影响。
6. 空白、白色豆格和未知格分开；无字且有纹理的不确定格不会记零。色卡外号不进入用量。为避免把色卡当制作图，新后备要求重复制作色号，少于5×5或超过40000格仍有支持限制；超过16000格的成功项保留位置、原文和解释，省略重复的字符候选，未知格仍保留详细证据。

这里确实读取文字，是为拼豆色号设计的小字识别，不冒称“完全不用OCR”。两个字体合成训练模型共444,910字节（约435KiB），加旧字形模板共635,352字节（约620KiB）。训练没有使用图纸或参考答案；从头训练逐参数复现记录在 [training-reproduction.json](training-reproduction.json)，训练入口 [train_glyph_model.py](train_glyph_model.py)，许可 [font-notices.txt](font-notices.txt)。推理不加载PyTorch，不安装通用OCR引擎，没有新增依赖或服务。
