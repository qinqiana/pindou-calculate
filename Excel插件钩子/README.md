# Excel 插件钩子（Excel Hook）

> 豆计的「侧翼获客」产物：一张开箱即用的 **MARD 221 拼豆库存表（增强版）**，
> 服务仍在用 Excel/WPS 表格管豆子的存量用户，并作为后续 Excel/WPS 插件与 App 导流的入口。

定位详见竞品调研结论：图纸生成是红海，库存/用量管理是蓝海；大量拼豆玩家至今在用
小红书流传的 221 色 Excel 库存表（只能电脑端、无图纸联动、无预警）。
本目录是「比它好一截」的免费替代品 + 插件演进路线。

## 使用方法（30 秒）

1. 「库存总览」：在「当前库存」列录入手上豆子颗数；没录的色号留空即可，不参与统计。
2. 想拼某张图：「图纸缺口计算器」只填 **色号** 和 **需求颗数** 两列，其余自动。
3. 「补货清单」自动汇总缺货色号和数量。
4. 拼完把各色用量加进「累计已用」，数据条越长越是高频色，补货优先。

详细说明见工作簿内「使用说明」页。

## 与豆计 App 的规则对齐

表格沿用 [SPEC.md](../SPEC.md) 已确认的记账规则，方便用户日后无缝迁移到 App：

- 预警基准 = 该色首次录入或最近补货后的数量（默认 1000，对齐 SPEC「预填 1000」），消耗不重置基准
- 低库存按用户自设百分比判定（默认 10%）
- 缺口 = MAX(需求 − 库存, 0)，预估不改库存
- 估算/精确逐色标记
- 色卡 = MARD 221（9 色系），社区版屏幕参考色、非官方精确色值，记账以色号为准
  （数据来源：[`research/MARD221-参考色值-社区来源.csv`](../research/MARD221-参考色值-社区来源.csv)）

## 演进路线（钩子三级火箭）

1. **本模板（当前）**：零开发投放，小红书免费分享 = 获客 + 需求验证
2. **JSA 宏版（xlsm）**：批量盘点弹窗、整批提交、变动留痕 sheet（WPS/Excel 双兼容）
3. **WPS JS 加载项**：Vue3 任务窗格，复用 SPEC §8.2 的平台无关 TypeScript 业务规则
   （色号校验、缺口计算）；读写与 App 相同的 JSON 备份格式（SPEC §8.4），
   成为「Excel → Android App → 微信小程序」的迁移钩子

> 注意：WPS JS 加载项只能在 WPS 客户端内运行（不支持浏览器/手机端）；
> Office.js 加载项不覆盖 WPS 用户。拼豆人群以 WPS 免费版为主，优先 WPS 路线。
